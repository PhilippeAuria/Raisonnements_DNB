# Raisonnements_DNB

Application d'entraînement pour les élèves de 3ème, dédiée à la partie « Raisonnement et résolution de problèmes » de l'épreuve de mathématiques du Brevet des collèges (DNB).

## Description

Application web autonome (un seul fichier HTML) proposant des exercices de type DNB, inspirés des sujets réels (académies d'Amérique du Nord, Asie, Centres étrangers, Polynésie, Antilles, France...) mais entièrement réécrits pour éviter toute redite. Chaque exercice comporte plusieurs questions progressives, une correction détaillée et, le cas échéant, une figure géométrique.

## Fonctionnalités

- Mode **Entraînement** : filtrage par thème (12 thèmes du programme de 3ème : statistiques et probabilités, calcul littéral, fonctions, Pythagore/trigonométrie, Thalès, transformations du plan, proportionnalité, grandeurs et mesures, nombres, arithmétique/PGCD, algorithmique...).
- Mode **Épreuve complète** : tirage d'un sujet entier chronométré, dans les conditions de l'examen.
- Corrections détaillées, affichables/masquables question par question.
- Figures géométriques générées en SVG (Pythagore, Thalès, solides...).
- Interface simple, utilisable sur ordinateur, tablette ou smartphone.

## Utilisation

Ouvrir simplement `index.html` dans un navigateur, aucune dépendance ni connexion internet requise après téléchargement.

Version en ligne : https://auriaphilippe.forge.apps.education.fr/Raisonnements_DNB
